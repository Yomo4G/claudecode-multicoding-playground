# Actions — Handwritten Ephemeral SNS

## User（利用者）のアクション

### 投稿する

- 対象: 手書き → 投稿
- 手書きを撮影・取り込み、場に投稿する
- 投稿は画像として場に現れる

### 眺める

- 対象: 場・投稿
- 場を訪れ、投稿を読む
- 反応は必須ではない

### いいねする

- 対象: 投稿
- 1投稿に対して1人1回
- 取り消し可能

### 返信する

- 対象: 投稿
- 手書き画像1枚のみ
- 返信に対してさらに返信（チェーン）が可能
- 元の投稿が消滅すると、返信も一緒に消滅する

### 通報する

- 対象: 投稿
- ポリシーに反するコンテンツを運営者に報告する

### ミュートする

- 対象: 特定の利用者
- ミュートした利用者の投稿を非表示にする
- 相手に通知されない
- 解除可能

### 自分の投稿を削除する

- 対象: 自分の投稿
- 消滅前に自ら削除できる
- 削除は不可逆である

### 退会する

- 対象: 自分のアカウント
- サービスから完全に離脱する
- 退会時、残存する投稿も消滅する

## Operator（運営者）のアクション

### コンテンツを削除する

- 対象: ポリシーに反する投稿
- 通報または運営判断に基づく

### アカウントを停止する

- 対象: 利用者のアカウント
- ポリシー違反に基づく

### サービスを維持管理する

- 対象: サービス全体
- 技術的な運用・保守

## 消滅ルール

- 投稿の基本寿命は14日間である
- 返信（スレッド）がある場合、最新の返信の日時が生存判定の基準になる
- 最新の返信から14日以内であれば、親投稿は存続する

### 返信チェーン途中の返信が消滅した場合

- 最新のスレッドが投稿から14日以内 → 親投稿は残る
- 最新のスレッドが投稿から14日以上 → 親投稿ごと消滅する

### 返信がすべてなくなった場合

- 親投稿が投稿から14日以内 → 親投稿は残る
- 親投稿が投稿から14日以上 → 親投稿は消滅する

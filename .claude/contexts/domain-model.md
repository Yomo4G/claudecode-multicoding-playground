# Domain Model — Handwritten Ephemeral SNS

## Concepts

### Handwriting（手書き）

紙にペンで書かれた文字・文。
サービスの外側で生まれる。
サービスに取り込まれる前の状態。

### Post（投稿）

手書きが撮影・取り込まれ、サービス上に現れたもの。
投稿は画像として存在する。
投稿は時間経過により消滅する。
消滅後、投稿の痕跡は残らない。

### Disappearance（消滅）

投稿が時間経過により消えること。
消滅は不可逆である。
消滅後、投稿のエンティティ（画像）は残らない。
痕跡（記録、カウント、空白）も残らない。

### Place（場）

投稿が存在し、人が訪れる空間。
場は1つだけ存在する。
場は分割・分類されない。

## Relationships

- 手書きは撮影・取り込みにより投稿になる。
- 投稿は場に存在する。
- 投稿は時間経過により消滅する。
- 消滅した投稿は復元できない。

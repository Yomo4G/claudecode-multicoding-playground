# Design Policy

## Responsive Design (Mandatory)

All UI code generated by the AI must be responsive.
This rule applies regardless of the design method selected.

- Breakpoints are defined in `project.config.json` under `breakpoints`.
- The AI must use these breakpoints consistently across all components.
- The AI must not hardcode breakpoint pixel values in source code.
- If breakpoints are not yet configured (null),
  the AI must not generate UI code.

## Design Method

The design approach is selected during kickoff (Design Definition).
The `designMethod` field in `project.config.json` determines
how the AI approaches visual design during execution.

Possible values:
- `conversation`: Design decisions made through dialogue
- `image`: Design based on provided image or Figma
- `reference`: Design inspired by a well-known service
- `auto`: AI determines an appropriate modern design

Rules:
- The AI must not change the design method without human instruction.
- The AI must respect the selected reference service when applicable.
- Breakpoints can be updated by humans at any time
  by editing `project.config.json` directly.

# Placeholder Image Policy

During MVP development, placeholder images are used
instead of real assets.

All placeholder images must be SVG files generated by
`scripts/generate-placeholders.mjs`.

Rules:
- The AI must NEVER use external placeholder services
  (e.g., placeholder.com, picsum.photos, via.placeholder.com).
- The AI must NEVER embed base64-encoded images in source code.
- The AI must NEVER create image files manually.
  Always use the generation script.
- All placeholder images must live in the `placeholders/` directory
  within the appropriate public folder.
- When a component needs a placeholder image not covered by presets,
  the AI must use the custom CLI to generate it:
  `pnpm placeholders --name <name> --width <w> --height <h>`
- In source code, reference placeholders with root-relative paths:
  `/placeholders/<name>.svg`
- If the placeholders directory does not exist,
  the AI must run `pnpm placeholders` before writing UI code
  that references placeholder images.

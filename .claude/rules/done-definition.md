# Done Definition Rule

## 基本方針

- すべてのタスクは事前に明示的なDone基準を持たなければならない
- Done基準のないタスクは実行を開始してはならない
- タスクの状態は「完了」か「未完了」のどちらかのみである
- 部分的な完了は認めない

## Done判定

- AIが結果を確認して判定する
- 判定はDone基準に基づいて行う

## Done の最低条件

すべてのタスクは、以下の条件をすべて満たしたとき完了とする:

1. 定義されたDone基準をすべて満たしている
2. ユニットテストが通っている
3. コードレビューが完了している

## コードレビュー

- コードレビューはすべてのタスクに対して必須である

# Failure Handling Rule

## エラー・想定外の問題が発生した場合

- AIはまず自力でリトライ・修正を試みる
- 解決できない場合は停止して人間に報告する
- 人間への報告には以下を含める:
  - 何が起きたか
  - 何を試みたか
  - なぜ解決できなかったか

## コンテキストに問題があった場合

- AIが修正案を提案する
- 人間が承認してから修正を反映する
- 承認なしにコンテキストを変更してはならない

## ブロック時の対応

- 次のタスクが実行可能（依存関係がなく着手可能）な場合、ブロックされたタスクをスキップして移ることを許可する
- 直列タスク（前のタスクの完了が前提）の場合、スキップは不可
- ブロックの理由と状態は記録する

- プロジェクト初期化
- Vite 設定

- Vitest 設定

## T2: API 仕様設計（OpenAPI）

### Done 基準

- 全機能のエンドポイントが OpenAPI スペックとして定義されている
- リクエスト/レスポンスのスキーマが定義されている
- スペックがバリデーションを通る

### スコープ

- 全エンドポイント定義（認証、投稿、いいね、返信、ミュート、通報、モデレーション、ユーザー、退会）
- スキーマ定義
- エラーレスポンス定義

### 非スコープ

- API の実装
- データベース設計

### 依存

- T1

### 並列/直列

- T1 完了後に開始

## T3: API 実装（Hono + SQLite）

### Done 基準

- OpenAPI スペックで定義した全エンドポイントが Hono で実装されている
- SQLite テーブルが作成され、CRUD 操作が動作する
- フロントエンドから接続できる

### スコープ

- Hono ルート定義（OpenAPI スペック準拠）
- SQLite スキーマ定義・マイグレーション
- リクエストバリデーション
- エラーレスポンス実装

### 非スコープ

- フロントエンド実装
- 認証・認可の詳細実装（Phase 2 以降）
- パフォーマンス最適化

### 依存

- T2

### 並列/直列

- T2 完了後に開始

# Phase 2: 認証・コア機能

## T5: 認証

### Done 基準

- 登録画面（メールアドレス・パスワード・アカウント名）が動作する
- メール認証フローが動作する（モック）
- ログイン・ログアウトが動作する
- 認証状態に応じたルーティングガード（未認証→ログイン画面）が動作する
- テストが通る

### スコープ

- 登録画面
- ログイン画面
- ログアウト処理
- メール認証画面
- 認証状態管理
- ルーティングガード

### 非スコープ

- 実際のメール送信
- パスワードリセット
- ソーシャルログイン

### 依存

- T3, T4

### 並列/直列

- T3/T4 完了後に開始

---

## T6: 投稿作成

### Done 基準

- カメラ起動・撮影ができる
- 手書き判定が動作し、falseの場合は投稿不可となる
- プレビュー画面で確認・投稿ができる
- カメラロールへの保存が選択できる（デフォルトoff）
- 投稿が API に送信される（モック）
- テストが通る

### スコープ

- カメラ UI
- 撮影処理
- 手書き判定（モック）
- プレビュー画面
- 投稿確認・送信
- カメラロール保存オプション

### 非スコープ

- 手書き判定の実際のアルゴリズム
- 画像最適化
- 投稿後のフィード表示

### 依存

- T5

### 並列/直列

- T5 完了後に開始（T7 と並列可）

---

## T7: 場（フィード）

### Done 基準

- 投稿一覧が場として表示される
- 各投稿にアカウント名・アイコン・手書き画像・いいね数が表示される
- 投稿が新しい順に並ぶ
- テストが通る

### スコープ

- フィード画面
- 投稿カード表示
- 一覧取得（モック API）
- 表示順

### 非スコープ

- いいね・返信の操作
- 無限スクロール
- リアルタイム更新

### 依存

- T5

### 並列/直列

- T5 完了後に開始（T6 と並列可）

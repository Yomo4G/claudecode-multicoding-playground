# Phase 4: システム・管理

## T13: 自動消滅

### Done 基準

- 14日経過した投稿がフィードに表示されない
- 返信がある投稿は最新返信から14日で判定される
- 返信チェーン途中の消滅時、残存ルールが正しく動作する
- 消滅した投稿のいいね・返信も表示されない
- テストが通る

### スコープ

- フロントエンドでの消滅表示制御
- 14日寿命判定ロジック
- 返信延命ロジック
- 従属関係（いいね・返信）の消滅表示

### 非スコープ

- サーバーサイドの論理削除バッチ
- 物理削除
- 消滅アニメーション

### 依存

- T9

### 並列/直列

- T9 完了後に開始（T14 と並列可）
